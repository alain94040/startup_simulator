# AGENTS.md

the story-graph model, the turn & surfacing rules, the chapter design philosophy, coding
conventions, and which regression suites to run before calling a change done.

Read that file first; it is the single source of truth for this codebase. This file exists only
so agents that look for `AGENTS.md` by convention find their way there. (An earlier copy of the
guide lived here and drifted out of date — hence the pointer instead of a duplicate.)
